\begin{frame}{\textbf{What is LaTeX?}}

\LaTeX{} is a document preparation and typesetting system
commonly used for academic and technical documents.

\begin{itemize}
    \item Produces professional-looking documents
    \item Useful for scientific and technical writing
    \item Excellent support for mathematical equations
    \item Automatically numbers chapters and sections
    \item Provides consistent document formatting
\end{itemize}

\end{frame}



\begin{frame}{Structure and Formatting}

A LaTeX document consists mainly of:

\begin{enumerate}
    \item Document class
    \item Preamble
    \item Document body
\end{enumerate}

\vspace{0.5cm}

Important packages used in this assignment:

\begin{itemize}
    \item \texttt{geometry} -- controls page margins
    \item \texttt{xcolor} -- provides colors
    \item \texttt{sectsty} -- changes heading styles
    \item \texttt{fancyhdr} -- creates headers and footers
\end{itemize}

\end{frame}

\begin{frame}{Conclusion}

\begin{itemize}
    \item LaTeX is useful for professional document preparation.
    \item It provides excellent control over document structure.
    \item Packages make customization simple and powerful.
    \item Beamer can be used to create professional presentations.
\end{itemize}
